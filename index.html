    MAE101 - Introduction to Applied Mathematics

    Lý Thuyết Được Áp Dụng

    This course introduces students to the fundamental concepts and techniques in applied mathematics. Topics include calculus, differential equations, linear algebra, statistics, probability theory, and data analysis.

    Chương 1: Chapter 1: Introduction to Mathematical Thinking

    Introduction to the concepts of mathematical thinking and how it is applied in daily life.

    Chương 2: Chapter 2: Functions and Graphs

    Understanding functions, their graphs, and related concepts like domain and range.

    Chương 3: Chapter 3: Limits and Continuity

    Discussion on the concept of limits and continuity.

    Chương 4: Chapter 4: Differentiation

    Introduction to differentiation, its applications, and rules for computing derivatives.

    CSI104 - Computer Science I for Business and Technicians

    Lập trình máy tính cho doanh nghiệp và công nhân

    Course designed to provide students with a solid grounding in computer science principles and their applications within the business environment. Topics include: data structures, algorithms, programming languages, machine-level programming, operating systems, databases, networks, etc.

    Chương 1: Chapter 1: Introduction to Computer Science

    This chapter will introduce you to the basics of computer science and its role in business.

    Chương 2: Chapter 2: Data Structures and Algorithms

    Learn about data structures and algorithms, which are fundamental building blocks for writing efficient programs.

    SSG104 - Introduction to Computer Science and Programming

    Lớp tin học về Khoa Học Máy Tính và Lập Trình

    This course provides an introduction to computer science and programming. It covers the basics of programming, data structures, algorithms, and software engineering.

    Chương 1: Introduction to Computer Science

    An overview of what makes a computer a useful tool for modern life.

    Chương 2: Programming Basics

    A brief introduction to programming languages and syntax.

    Chương 3: Data Structures and Algorithms

    Introduction to the principles of data structures and algorithms used in computer science.

    Chương 4: Software Engineering Basics

    Understanding the basics of software development processes.

    PRO192 - Advanced Software Development Practices

    Quy trình phát triển phần mềm cao cấp

    This course introduces the principles and practices of advanced software development. It covers design patterns, testing strategies, project management techniques, security concerns, and more.

    Chương 1: Chapter 1: Software Design Patterns

    Introduction to software design patterns, their importance in software development, and examples of various design patterns.

    Chương 2: Chapter 2: Automated Testing Strategies

    An overview of different automated testing strategies including unit testing, integration testing, and system testing.

    Chương 3: Chapter 3: Project Management Techniques

    Exploration of various project management techniques such as agile development, waterfall model, and their application in software projects.

    Chương 4: Chapter 4: Security Concerns

    An introduction to security issues in the context of software development. Topics include secure coding practices, encryption techniques, and cybersecurity threats.

    MAD101 - Applied Mathematics for Data Science

    Khoa học dữ liệu kỹ thuật Toán học Áp dụng

    MAD101 is an introduction to data science, providing students with the basics of programming and statistical analysis using Python for data manipulation and visualization. Topics include: basic python syntax, data structures, control flow, functions, libraries and packages in python, handling datasets in pandas, data cleaning, exploratory data analysis, descriptive statistics, inferential statistics, hypothesis testing, regression modeling, decision trees, and clustering.

    Chương 1: Introduction to Data Science

    This chapter introduces the concepts of data science.

    Chương 2: Python for Data Manipulation and Visualization

    This chapter covers basic python syntax, libraries and packages in Python for data manipulation and visualization.

    Chương 3: Data Cleaning

    In this chapter, students will learn how to handle datasets in pandas and perform data cleaning.

    Chương 4: Exploratory Data Analysis

    This chapter introduces the concept of exploratory data analysis using descriptive statistics.

    Chương 5: Statistical Inference and Hypothesis Testing

    In this chapter, students will learn about statistical inference and hypothesis testing.

    Chương 6: Regression Modeling

    This chapter introduces the concept of regression modeling.

    Chương 7: Decision Trees

    In this chapter, students will learn about decision trees and how to use them for prediction.

    Chương 8: Clustering

    This final chapter introduces the concept of clustering and its applications in data science.

    OSG202 - Operating System Concepts - Part 1 (Computer Systems)

    Lớp học Công nghệ Hệ thống Máy Tính - Phần 1

    This course introduces the fundamental concepts in computer system design and implementation. It will provide an overview of hardware/software interface, memory hierarchy, and a survey of operating systems.

    Chương 1: Chapter 1: Introduction to Computer Systems

    Introduction to the course, fundamental concepts in computer science and the role of a computer system designer.

    Chương 2: Chapter 2: The Nature of Programs

    Examination of programming languages and program structure.

    Chương 3: Chapter 3: Processes, Threads, and Concurrency

    Introduction to processes and threading; study on concurrent execution.

    CSD201 - Introduction to Computer Science and Programming

    Lập trình và khoa học máy tính cơ bản

    Course Description: This course introduces the basic principles of computer science and programming, covering topics such as algorithms, data structures, programming languages, machine learning, artificial intelligence, and more. It also covers software engineering principles.

    Chương 1: Introduction to Computer Science

    In this chapter, we introduce the basics of computer science including its history, applications, concepts like algorithms, data structures, programming languages, and more.

    Chương 2: Python Programming Basics

    This chapter dives into Python's syntax and semantics. It covers basic data types (integers, strings, lists), control flow statements (if-else, for, while loops), functions, error handling, and more.

    Chương 3: Data Structures & Algorithms

    In this chapter, we explore the most commonly used data structures like arrays, linked lists, stacks, queues, trees, hash tables. We also introduce basic algorithmic concepts (searching and sorting) and techniques.

    Chương 4: Web Programming Basics

    We start this chapter with an introduction to web programming languages like HTML/CSS for frontend development, JavaScript for client-side scripting. We then move onto backend technologies like Node.js and databases like MongoDB.

    Chương 5: Introduction to Machine Learning

    This chapter introduces the basics of machine learning including what it is, why it's important, how data can be used effectively for machine learning tasks, as well as basic machine learning algorithms and tools like NumPy, Pandas, Matplotlib.

    Chương 6: Introduction to Artificial Intelligence

    This chapter introduces the basics of artificial intelligence including what it is, why it's important, how data can be used effectively for AI tasks, as well as basic AI algorithms and tools like TensorFlow.

    DBI202 - Database Systems for Information Management

    Hệ Thống CSDL cho Quản Lý Thông Tin

    This course provides students with a solid understanding of database design and management, using standard relational model. It focuses on topics such as SQL programming, data modelling, transaction control, indexing, security, performance tuning, and distributed databases.

    Chương 1: Introduction to Database Systems

    This chapter introduces the basic concepts of database systems.

    Chương 2: Relational Model: Structure & Querying

    It discusses the relational model, including entities and attributes, primary keys, foreign keys, joins, and subqueries in SQL.

    PRN211 - Professional Research in Networks

    Cổ đại học mạng

    Môn PRN211 cung cấp kiến thức và kỹ năng liên quan đến lĩnh vực mạng xã hội. Nó bao gồm các chủ đề về lập trình, khoa học dữ liệu, phân tích dữ liệu mạng, môi trường mạng xã hội và các chủ đề liên quan khác.

    Chương 1: Lập trình mạng

    Chương này tập trung vào cách lập trình mạng. Bao gồm các kiến thức về việc sử dụng phần mềm, ngôn ngữ lập trình, v.v.

    Chương 2: Khoa học dữ liệu

    Chương này tập trung vào cách sử dụng kho lưu trữ, xử lý và hiển thị dữ liệu. Nó bao gồm các chủ đề như lưu trữ, phân tích, tính toán và hiển thị dữ liệu.

    Chương 3: Phân tích dữ liệu mạng

    Chương này tập trung vào cách phân tích dữ liệu được chia sẻ trên mạng. Nó bao gồm các kiến thức về cách tính toán, xử lý và hiển thị dữ liệu.

    Chương 4: Môi trường mạng xã hội

    Chương này tập trung vào cách hoạt động của mạng xã hội. Nó bao gồm các kiến thức về việc sử dụng, phân tích và tư vấn trong môi trường này.

    SWP391 - Software Project Management

    Quản lý dự án phần mềm

    SWR302 - Software Testing and Quality Assurance Specialist Course

    Khoá học Chuyên Nhà Thiết Kế Phần Mềm và Kiểm Tra Chất Lượng

Học viên cũng có cơ hội được tư vấn, tham gia vào nhóm kiểm tra chất lượng trong quá trình phát triển các dự án.

    PRM392 - Programming for Data Science

    Khoa học dữ liệu và lập trình

    This module introduces students to the principles and practices of programming in a data-centric environment. It covers fundamental concepts, tools, and techniques required for manipulating data using Python and other languages.

    Chương 1: Introduction to Data Science

    This chapter introduces the concept of data science, including its applications and how it differs from traditional software development.

    Chương 2: Programming Concepts

    This chapter discusses fundamental programming concepts such as variables, control structures, functions, and data types in Python.

    Chương 3: Data Handling with Pandas

    In this chapter, we explore the powerful data handling library 'pandas' in Python. We cover how to read and write data, perform basic operations on data frames, and handle missing values.

    Chương 4: Data Visualization with Matplotlib

    Matplotlib is a powerful tool for creating static, animated, and interactive visualizations in Python. This chapter covers its basics including line plots, scatter plots, bar charts, histograms, etc.

    Chương 5: Machine Learning Basics

    We cover basic machine learning concepts like supervised/unsupervised learning, training and testing datasets, overfitting and underfitting. We also discuss the importance of feature scaling in machine learning algorithms.
